# Análisis del comportamiento de compradores en comercio electrónico

## Descripción
Este proyecto tiene como finalidad analizar el comportamiento de los visitantes de un sitio de comercio electrónico para conocer algunas características relacionadas con las compras.

## Objetivo
Analizar los datos de las visitas para identificar patrones y utilizar modelos que permitan intentar predecir si una sesión termina en una compra.

## Conjunto de datos
Se utiliza el conjunto de datos Online Shoppers Purchasing Intention Dataset, obtenido del repositorio UCI Machine Learning Repository.

Contiene 12,330 registros y 18 variables relacionadas con el comportamiento de los visitantes.
